# カット倶楽部エンドレス — 参考HP制作ブリーフ

## 1. Project goal

「カット倶楽部エンドレス」の参考ホームページを制作する。

今回の第一目的は、派手に新規集客を煽ることではなく、

- 店舗の考え方を分かりやすく伝える
- 通いやすさ・利用しやすさを伝える
- 既存客・リピーターにも安心して見てもらえる
- Google / Hot Pepper Beauty以外にも店舗を知る入口をつくる
- オーナー側の更新負担を極力増やさない

Webサイトを作ること。

## 2. Source-derived positioning

商談内容から、サイトの中心メッセージは以下とする。

### Core value

「来ていただいたお客様に、喜んで帰っていただけるお店」

### Strengths to communicate

- 一人ひとりのお客様に丁寧に向き合う姿勢
- 何度でも通ってもらえるお店を目指している
- 通いやすい料金設定を大切にしている
- リピーターのお客様を大切にしている
- 大量集客より、無理のない範囲でお客様を迎える考え方
- GoogleやHot Pepper Beautyからも店舗を知ってもらっている
- Web操作を頻繁に行わなくても運用しやすいサイトが望ましい

## 3. Tone & design proposal

This is a DESIGN PROPOSAL, not a sourced business fact.

Direction:
- approachable
- local
- warm
- clean
- trustworthy
- not luxury-heavy
- not flashy
- easy for a broad age range to read

Suggested visual mood:
- warm off-white background
- charcoal text
- one muted accent color such as sage / dusty blue / soft terracotta
- generous whitespace
- rounded but not childish UI
- large readable Japanese typography
- clear reservation CTA

Avoid:
- overly glamorous beauty-salon styling
- tiny light-gray text
- excessive animations
- cramped cards
- ultra-thin fonts
- aggressive sales copy

### Concept

Heading:
`来てくださった方に、`
`笑顔で帰っていただけるように。`

Body:
オーナーの「来ていただいたお客様に喜んで帰ってもらえるお店にしたい」という考え方を、Web向けに自然な文章へ整える。

### Three points

1. `一人ひとりに、丁寧に`
   - 一人で対応するサロンだからこそ、お客様と向き合う時間を大切にする。

2. `何度でも通いやすく`
   - リピーターとして長く通ってもらえることを大切にし、利用しやすさを意識した店舗づくり。

3. `無理なく、心地よく`
   - 予約枠を調整しながら、一人ひとりを落ち着いて迎えられる運営を大切にする。

## 5. Copy principles

- Use short Japanese sentences suitable for websites.
- Do not overclaim.
- Do not say "地域No.1", "圧倒的", etc.
- Do not promise excessive customer acquisition.
- Prioritize warmth, repeat visits and approachable pricing.
- Avoid presenting "low price" as "cheap quality".
- Prefer wording such as `通いやすい`, `続けやすい`, `気軽に`.

- 1–2 character orphan lines
- splitting `から`, `こと`, `たい` etc.
- broken store name
- forced `<br>` everywhere
