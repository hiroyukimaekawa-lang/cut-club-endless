# 日本語改行 Before / After 例

## Case 1: 助詞の孤立

Before:
```text
大切な人との時間
を
もっと特別に
```

After:
```text
大切な人との時間を
もっと特別に
```

## Case 2: Heroが長すぎる

Before:
```text
地域のお客様に長年愛され続ける温かく居心地の良い店舗を目指しています
```

After:
```text
地域に愛される、
温かいお店を目指して。
```

## Case 3: 固有名詞の分断

Before:
```text
SANGL
IER COFFEE
```

After:
```text
SANGLIER COFFEE
```

またはブランドデザイン上許容される場合のみ:
```text
SANGLIER
COFFEE
```

## Case 4: 商品名の分断

Before:
```text
季節のフルーツパ
フェ
```

After:
```text
季節のフルーツ
パフェ
```

ただし正式商品名が「季節のフルーツパフェ」の場合は、可能なら商品名全体を保持する。

## Case 5: 本文への過剰なbr

Before:
```html
<p>
地域の皆様に<br>
長く愛されるお店を<br>
目指して日々営業しています。
</p>
```

After:
```html
<p>
地域の皆様に長く愛されるお店を目指して日々営業しています。
</p>
```

本文はコンテナ幅・line-height・段落で整える。

## Case 6: 「から」の途中で分断

Before:
```text
一つのチームか
ら、文化の輪へ。
```

After:
```text
一つのチームから、
文化の輪へ。
```

## Case 7: 「たい」の途中で分断

Before:
```text
誰もが輝ける場所
を、光と音でつくりた
い。
```

After:
```text
誰もが輝ける場所を、
光と音でつくりたい。
```

## Case 8: 「こと」の途中で分断

Before:
```text
上手になる前に、
夢中になれるこ
と。
```

After:
```text
上手になる前に、
夢中になれること。
```

## Case 9: カード内コピーは全件Visual QAする

カードが複数並ぶ場合、1枚だけではなく全カードを確認する。

確認対象:
- 行数のばらつき
- 文節途中の分断
- 1〜2文字の孤立
- カード幅ごとの折り返し
- Desktop / Mobile双方での読みやすさ

修正後も必ず再度スクリーンショットまたは実画面で確認する。
